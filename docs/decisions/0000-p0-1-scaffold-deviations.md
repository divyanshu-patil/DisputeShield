# 0000. P0-1 scaffold: deviations from 02-monorepo-structure.md

Date: 2026-10-17. Task: P0-1 (and the starter adoption in P1-0). Spec: pack v2 (Fastify API, Supabase, Ollama Cloud, Render Workflows).

| Spec                                                                             | Built                                                                                                                                                                                         | Why                                                                                                                     |
| -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| create-turbo scaffold (`apps/docs`, `@repo/*`, Next 16.3.8, TS 7)                | removed, replaced with `@ds/*`                                                                                                                                                                | spec versions; typescript-eslint 8.71 supports TS < 6.1                                                                 |
| `engines.node >=20.9`, `.nvmrc` 20.9+                                            | `>=22.13`, `.nvmrc` = 24                                                                                                                                                                      | pnpm 11 needs Node >= 22.13; Vitest 5 and commander 15 need ^22.12; Node 20 is EOL                                      |

| versions as ranges / `latest-at-install` / starter `^` ranges                    | exact pins; shared ones in the pnpm `catalog:` (`pnpm-workspace.yaml`)                                                                                                                        | AGENTS.md: pin what you install.
